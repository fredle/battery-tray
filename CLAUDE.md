# Battery Tray

Battery level of your Bluetooth headphones, mouse and keyboard in the tray, with low warnings.

A Windows micro app generated by app-factory. The spec is in `SPEC.md`.

## Stack (fixed - do not change)

- Rust 2024, `eframe`/`egui` 0.36 (glow), single exe, `#![windows_subsystem = "windows"]`.
- Velopack for install and self-update from GitHub Releases. Released by
  `.github/workflows/release.yml` on `v*` tags: Trusted Signing, GitHub
  Release, blob mirror, Microsoft Store submission.
- eframe 0.36's `App` trait method is `fn ui(&mut self, ui: &mut egui::Ui, frame: &mut eframe::Frame)`,
  and panels take that `Ui` (`CentralPanel::default().show(ui, ...)`).
  Side/top/bottom panels are `egui::Panel::left/right/top/bottom(id)` -
  there is no `TopBottomPanel` or `SidePanel` in 0.36.

## Factory-owned files - leave as-is

- `src/update.rs`, `src/main.rs` (only add `mod` lines),
  `.github/workflows/release.yml`, `build.rs`.
- The footer in `src/app.rs` (auto-update toggle + version) must stay.

## Two processes (keep it that way)

The app's resident cost is what users judge it by, so egui never runs in
the process that stays in the tray:

- **Tray process** (`tray.rs`, the default and `--tray`): hidden Win32
  window, tray icons, menu, balloons, the monitor thread (`monitor.rs`,
  `source.rs`) and Windows' power/device/session signals (`signals.rs`).
  No egui, no window, efficiency mode. A few MB.
- **Window process** (`--ui flyout|pinned|hidden`, handled in `app::run`):
  eframe/egui, started by the tray process on a click, Open or a second
  start (`hidden` while the pointer is on an icon), ends itself `LINGER`
  after it is hidden (`link.rs`), and when the tray process ends.
- They talk through `ipc.rs`: tray to window, JSON in `WM_COPYDATA`
  (devices, click, Open, Quit); window to tray, posted messages (hello,
  settings changed, refresh). Settings go through settings.json, history
  through history.json. Velopack's hooks still run first in both (main.rs).
- `--shots` runs the window alone, as before.
- `tools/measure.ps1` measures memory, CPU, wake-ups, writes, start and
  flyout times against a scratch LOCALAPPDATA: run it before and after
  anything that could change what the app costs in the tray.

## Rules for building the app

- Implement the spec in `src/app.rs` and new modules. Keep it small and
  dependency-light; every new crate needs a reason.
- Persist state under `settings::data_dir()` (%LOCALAPPDATA%\BatteryTray).
- No network calls except the update check, unless the spec requires them.
- No telemetry, no accounts, no admin rights.
- Put logic that can be tested in plain functions and cover it with
  `#[cfg(test)]` unit tests. `cargo build --release` and `cargo test` must
  pass with no warnings.
